# Diganta Travel Agency

Official website for Diganta Travels & Tours.

## Tech Stack
- Vite
- GSAP & ScrollTrigger
- Lenis Smooth Scroll
- Vanilla HTML5 / CSS3 / JavaScript (ES Modules)

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Production Build
```bash
npm run build
```
